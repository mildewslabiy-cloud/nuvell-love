# PERSONAL FILE — готовый сайт

## Что тебе осталось сделать

### 1. Вставить фотографии

Открой папку `photos`.

Там должны лежать 5 файлов:

- `photo1.jpg` — **милая/нежная фотография** для первого появления.
- `photo2.jpg` — **дерзкая/уверенная фотография**.
- `photo3.jpg` — **спокойная личная фотография**, которая подходит к теме доверия.
- `photo4.jpg` — **самая красивая/эмоциональная фотография** для серьёзной части.
- `photo5.jpg` — **твоя любимая фотография для финала**.

Лучше использовать JPG или PNG.

Если твои фотографии называются иначе — просто переименуй их в эти названия.

ВАЖНО: если фото очень большие (например 10–20 МБ), лучше уменьшить их примерно до 1–3 МБ. Для телефона этого более чем достаточно.

### 2. Проверить сайт

Дважды кликни по `index.html`.

Он откроется в браузере.

Пройди сайт от начала до конца и проверь фотографии.

### 3. Как изменить текст

Весь основной текст находится в `index.html`.

Если захочешь поменять какую-нибудь фразу — открой `index.html` через Блокнот или VS Code и измени нужный текст.

### 4. Как сделать ссылку, которую можно отправить ей

Самый простой вариант — бесплатный Netlify Drop.

1. Открой https://app.netlify.com/drop
2. Зарегистрируйся или войди.
3. Перетащи туда ВСЮ папку сайта `nuvell_love_site`.
4. Netlify создаст публичную ссылку.
5. Скопируй эту ссылку и отправь ей.

НЕ загружай только `index.html`. Нужно загрузить всю папку вместе с `style.css`, `script.js` и папкой `photos`.

### 5. Если Netlify попросит подтвердить аккаунт

Пройди обычную регистрацию/подтверждение. После публикации ссылка будет открываться с телефона.

### 6. Важное

Не удаляй и не переименовывай:

- `style.css`
- `script.js`
- папку `photos`
- файлы `photo1.jpg` ... `photo5.jpg`

если не меняешь соответствующие пути в HTML.

Сайт уже адаптирован под телефон.

## Если хочешь заменить фото позже

Просто замени файл:

`photos/photo1.jpg`

новой фотографией с точно таким же именем.

То же самое для `photo2.jpg` ... `photo5.jpg`.

Сама структура сайта останется прежней.
